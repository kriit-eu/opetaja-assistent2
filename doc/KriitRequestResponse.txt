# The following request is sent to Kriit to get the differences between the assignments in the journal and the assignments in Kriit. The response is then used to replace the mismatched grades table in journals.
# The server expects the body to be a JSON array of objects, where each object represents a subject and its assignments and its grades.
# The server returns a JSON array of objects, mimicing the request body, where each object represents differences between the Tahvel and Kriit in that subject/journal (teacher name, subject name, assignment name, student name, and grade).
# The associated id fields are always returned if there is a mismatch in order to allow for easy mapping between the two systems.
POST http://localhost/kriit/api/subjects/getDifferences
Content-Type: application/json
Authorization: Bearer demo
Accept: application/json
