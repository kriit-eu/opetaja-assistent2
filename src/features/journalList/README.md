# Journal List Features

This directory contains features that enhance the journal list page in Tahvel.

## Implemented Features

- **Journal List Sync**: Synchronization between Tahvel and Kriit systems
  - Sends the following data to Kriit:
    - list of all journals that have grades
  - Lists the following discrepancies between Tahvel and Kriit, by journal and assignment:
    - grade discrepancies between Tahvel and Kriit
    - due date differences between Tahvel and Kriit
  - Displays a banner showing differences that need to be synced

- **Colored Indicators**: Visual indicators for incomplete grading (partially implemented)
